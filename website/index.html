Catatan Windows 10 & 11

    Antarmuka Asli

    Cuplikan layar aplikasi desktop

    Tangkapan layar asli dari jendela Dengerin Desktop di Windows. Klik gambar mana saja untuk melihat ukuran penuh.

    Arsitektur Audio

    Dirancang untuk pemutaran stabil tanpa pelacakan

    Dengerin memisahkan mesin streaming dan cache di backend Go agar antarmuka Svelte tetap responsif saat memutar audio jangka panjang.

    Kendali frekuensi 5-band (60Hz hingga 14kHz) berjalan lokal via Web Audio API dan internal CORS streaming proxy.

    Failover Multi-Sumber

    Menarik stream audio Opus/AAC langsung lewat katalog YouTube Music dengan rotasi instance otomatis ke Piped dan Invidious bila server lambat, serta menyaring podcast atau vlog.

    Cache Lokal & Equalizer

    Menyimpan lagu putaran ke disk dengan batas kuota LRU yang dapat diatur (termasuk pindah drive), ditambah equalizer studio 5-band, 8 preset suara, crossfade, dan mode hemat kuota.

    Playlist Mosaik & Berbagi P2P

    Membuat cover art kolase 2x2 otomatis dari empat lagu teratas, mengimpor playlist publik YouTube atau Spotify, serta bertukar daftar putar melalui kode Base64 atau berkas JSON.

    Integrasi Native Desktop

    Menyediakan Floating Mini Player (Always on Top), kontrol media keyboard (Windows SMTC), System Tray, Discord Rich Presence, timer tidur smooth fade-out, dan 1-click updater.

    Riwayat pembaruan terbaru

    Disarikan langsung dari berkas CHANGELOG.md repositori proyek. Tekan Ctrl+F untuk mencari catatan versi tertentu secara instan.

    v1.4.1 Isolasi Lagu Populer & Sinkronisasi Versi 8 November 2026

    Memisahkan state katalog tren beranda dari hasil pencarian agar query artis tidak menimpa daftar Lagu Populer saat input dibersihkan.

    • State daftar Lagu Populer terlindungi saat melakukan pencarian musisi.
    • Menghapus teks pencarian langsung mengembalikan katalog tren beragam.
    • Label versi pada dialog Pengaturan dan tombol Apa yang Baru terhubung dinamis ke konstanta rilis.
    v1.4.0 Redesign Antrean, Aksesibilitas & Auto-Update 7 November 2026

    Pembaruan antarmuka antrean 1 baris, progress bar updater live (MB/s), dukungan navigasi Escape dan keyboard penuh, serta stabilitas cold-start.

    • Auto-updater menampilkan byte terunduh, kecepatan transfer, dan restart in-place otomatis.
    • Dukungan aksesibilitas Escape, aria-label lengkap, focus-visible kontras tinggi, dan prefers-reduced-motion.
    • Perombakan laci antrean dengan aksi Bersihkan Sisa dan perbaikan konflik file .tmp saat cold start.
    v1.3.2 Infinite Scroll Pencarian & Pipeline Installer 3 November 2026

    Memulihkan token kontinuitas pencarian tanpa batas, persistensi batas disk cache LRU, serta kelengkapan build NSIS installer Windows pada CI/CD.

    • Pencarian memuat 20+ lagu lanjutan secara otomatis saat halaman digulir.
    • Kuota penyimpanan LRU (500 MB hingga Tanpa Batas) tersimpan permanen setelah restart.
    • Pipeline GitHub Actions menghasilkan artefak Multi-OS lengkap.
    v1.3.0 Lokasi Folder Cache Kustom & Mode Eco Default 3 November 2026

    Menambahkan kebebasan memilih direktori cache di drive eksternal dengan migrasi file audio otomatis dan pengingat direktori upgrade di installer.

    • Pindahkan direktori cache audio antar-drive tanpa kehilangan lagu tersimpan offline.
    • Mode Eco aktif sebagai bawaan untuk hemat kuota data.
    v1.2.0 SMTC Windows, Discord RPC & Impor Playlist 3 November 2026

    Integrasi tombol media hardware, Discord Rich Presence via Named Pipe, tab lagu offline terpin, dan algoritma rekomendasi FYP multi-artis.

    • Impor tautan playlist publik YouTube maupun Spotify langsung ke pustaka lokal.
    • Lagu favorit dan offline terlindungi agar tidak ikut terhapus pembersihan cache LRU.
