**Versi Target:** v1.2.0  
**Tanggal Desain:** 3 November 2026  
**Status:** Approved via /grill-me

---

## 1. Ringkasan Eksekutif & Latar Belakang

Dengerin Desktop telah mencapai fondasi streaming yang tangguh pada v1.1.2. Namun, ada kebutuhan besar untuk menjadikan Dengerin sebagai pemutar musik harian sekelas Spotify/Apple Music:
1. **Algoritma FYP (Untuk Anda) Sebelumnya Cacat:** Algoritma lama memutus pencarian (`break`) segera setelah mengumpulkan 16 lagu dari artis pertama, menyebabkan rekomendasi monoton 100% dari 1 musisi/channel terakhir yang diputar.
2. **Ketiadaan Integrasi OS Native:** Tombol keyboard multimedia, kontrol Bluetooth headset, overlay volume Windows (SMTC), dan Discord Rich Presence belum terhubung.
3. **Keterbatasan Ekosistem Playlist & Offline:** Pengguna belum bisa mengimpor playlist dari tautan YouTube/Spotify publik, belum memiliki antarmuka untuk melihat dan memutar koleksi lagu yang tersimpan di disk cache saat internet terputus, dan belum ada Sleep Timer.
4. **Jeda Antar Lagu:** Masih ada jeda *buffering* antar lagu saat berganti trek dan belum ada fitur *audio crossfade*.

Pembaruan **v1.2.0** menyatukan seluruh perbaikan dan fitur baru ini ke dalam satu paket rilis terpadu.

## 2. Spesifikasi Fungsional per Komponen

### A. Algoritma Rekomendasi FYP Baru (Smart Multi-Artist Discovery)
- **Multi-Artist Pool:** Mengumpulkan 5+ artis teratas berdasarkan skor afinitas (gabungan riwayat putar `history`, `favorites`, dan `playlists`).
- **Cap Maksimal 2 Lagu per Artis:** Menjamin tidak ada satupun musisi yang mendominasi lebih dari 2 lagu di feed FYP.
- **YouTube Mix & Discovery Query:** Menggunakan pencarian radio/mix (`"{artist} mix"` atau query musisi terkait) untuk menggali lagu dan artis serupa yang satu genre.
- **Interleaving Round-Robin & Dynamic Fisher-Yates Shuffle:** Mengambil 1 lagu dari tiap artis secara bergantian lalu mengacak urutannya setiap kali tombol *Segarkan* ditekan.
- **Deduplikasi dengan Top Played:** Mengecualikan lagu-lagu yang sudah ada di daftar *Sering Kamu Putar*.

### B. Integrasi Desktop Native & Kontrol Media
- **Windows SMTC & MediaSession API (`navigator.mediaSession`):**
  - Mengirimkan metadata lengkap (`title`, `artist`, `album`, `artwork`) ke Windows Shell & Webview2.
  - Menghubungkan action handler: `play`, `pause`, `previoustrack`, `nexttrack`, `seekbackward`, `seekforward`, `seekto`.
  - Merespons tombol media hardware keyboard & Bluetooth headset tanpa membuka jendela aplikasi.
- **System Tray & Dialog Konfirmasi Tutup:**
  - Ikon aplikasi di notification tray Windows dengan menu klik-kanan: *Putar/Jeda*, *Lagu Berikutnya*, *Lagu Sebelumnya*, *Buka Dengerin*, *Keluar*.
  - Dialog modal konfirmasi saat tombol "X" ditekan: *"Tetap putar musik di background?"* dengan checkbox *"Ingat pilihan saya"* dan toggle di Pengaturan.
- **Discord Rich Presence (RPC):**
  - Modul Go lokal yang berkomunikasi via Named Pipe (`\\.\pipe\discord-ipc-0`).
  - Menampilkan aktivitas *"Mendengarkan [Lagu] oleh [Artis]"* dengan timestamp durasi dan tombol Dengerin. Default aktif dengan toggle di Pengaturan.

### C. Ekosistem Playlist & Mode Offline
- **Import Playlist dari Luar (YouTube & Spotify):**
  - Dukungan tautan URL YouTube / YT Music Playlist via backend resolver (`/playlists/{id}`).
  - Scraper publik Spotify Embed (`https://open.spotify.com/embed/playlist/{id}`) untuk mengekstrak daftar `Judul` dan `Artis` tanpa akun Spotify, lalu mencocokkannya ke audio YouTube.
  - Modal pratinjau daftar lagu sebelum disimpan menjadi playlist lokal baru.
- **Tab Khusus 'Tersimpan / Offline' & Tombol Simpan Offline:**
  - Halaman baru di navigasi Sidebar: **Tersimpan / Offline**.
  - Tombol aksi *"Simpan Offline"* di setiap baris lagu (`TrackItem.svelte`) dan tombol *"Simpan Seluruh Playlist Offline"*.
  - Mengunci audio ke disk cache permanen via `AudioCacheManager` (pinned tracks).
  - Penanganan otomatis: saat status koneksi internet terputus (`$networkStore.isOnline === false`), aplikasi mengarahkan pengguna ke koleksi lagu offline yang siap diputar.
- **Sleep Timer (Pengatur Waktu Tidur):**
  - Ikon timer di Player Bar dan Queue Drawer.
  - Preset pilihan: **15m, 30m, 45m, 60m, Akhir Lagu Saat Ini**, dan **Kustom (menit)**.
  - Fade-out volume halus selama 5 detik sebelum pemutaran otomatis dijeda.

### D. Audio Polish & Zero Latency
- **Zero-Latency Pre-fetch:**
  - Otomatis melakukan pre-fetch stream URL dan *early buffer download* untuk lagu berikutnya di antrean saat sisa durasi lagu berjalan mencapai **15 detik**.
  - Transisi lagu berikutnya instan (0ms buffering delay).
- **Audio Crossfade:**
  - Slider durasi Crossfade di Pengaturan Audio (**0 s/d 10 detik**, default **3 detik**).
  - Mengatur Web Audio API `GainNode` ramp saat pergantian lagu.

## 3. Batasan Teknis & Arsitektur
- **Backend:** Go 1.25, Wails v2.17.
- **Frontend:** Svelte 4/5, TypeScript, Tailwind CSS v4.
- **Zero Cloud Cost:** Seluruh fitur berjalan 100% lokal di komputer pengguna tanpa server berbayar.
- **Keamanan & Efisiensi:** Cache audio terbatas dengan batas kuota disk yang dapat disetel, Discord IPC tanpa ketergantungan library eksternal berat.
