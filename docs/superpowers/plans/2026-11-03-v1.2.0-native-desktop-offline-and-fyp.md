# Dengerin v1.2.0: Native Desktop, Ekosistem Offline, Audio Polish & Algoritma FYP Baru Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menghadirkan pembaruan mayor `v1.2.0` yang mencakup perombakan total algoritma FYP (multi-artist interleaving & dynamic shuffle), integrasi OS native (Hardware Media Keys / Windows SMTC, System Tray dengan dialog konfirmasi tutup, Discord Rich Presence), ekosistem playlist & offline (impor playlist YouTube & Spotify Embed scraper, tab khusus musik offline dengan download manual, sleep timer dengan volume fade-out 5 detik), serta audio polish (zero-latency pre-fetch & audio crossfade).

**Architecture:** 
- **Backend (Go 1.25):** 
  - Overhaul rekomendasi FYP di `app.go` dengan multi-artist round-robin pool, batasan max 2 lagu per artis, discovery query mix, dan deduplikasi.
  - Modul Discord RPC (`backend/discord.go`) menghubungkan Named Pipe lokal Windows `\\.\pipe\discord-ipc-0`.
  - Playlist import resolver (`backend/playlist_import.go`) untuk YouTube playlist ID & Spotify Embed HTML scraper.
  - Pengelolaan pinned offline cache di `backend/audiocache.go` dan `app.go` (`SaveTrackOffline`, `GetOfflineTracks`, `RemoveOfflineTrack`).
  - System Tray Win32 di `app_windows.go` yang terhubung ke Wails runtime window visibility.
- **Frontend (Svelte 4/5, TypeScript, Tailwind CSS v4):**
  - Layanan `mediaSessionService.ts` mengikat `navigator.mediaSession` dengan `playerStore.ts` untuk kontrol hardware keyboard/Bluetooth.
  - Dialog modal konfirmasi tutup `CloseConfirmModal.svelte` saat tombol "X" ditekan.
  - Halaman baru `OfflineView.svelte` di Sidebar untuk memutar musik tersimpan saat tanpa koneksi internet.
  - Modal impor playlist `ImportPlaylistModal.svelte` dengan pratinjau daftar lagu.
  - Store timer tidur `sleepTimerStore.ts` dan modal pemilih durasi `SleepTimerModal.svelte` dengan fade-out 5 detik.
  - Pre-fetch queue watchdog pada 15 detik sebelum akhir lagu di `playerStore.ts` dan slider crossfade di `settingsStore.ts` & `SettingsModal.svelte`.
- **Versioning:** Bump versi dari `1.1.2` ke `1.2.0` di seluruh konfigurasi Go, Wails, Svelte, NSIS, dan `changelogs.ts`.

**Tech Stack:** Go 1.25, Wails v2.17, Svelte 4/5, TypeScript, Web Audio API, MediaSession API, Tailwind CSS v4, Win32 API.

**Spec:** [docs/superpowers/specs/2026-11-03-v1.2.0-desktop-offline-fyp-design.md](file:///d:/PROJECT/GAWEAN/PROJECT/APP/Dengar/docs/superpowers/specs/2026-11-03-v1.2.0-desktop-offline-fyp-design.md)

## Global Constraints
- Bahasa antarmuka: Bahasa Indonesia yang modern, ramah, dan ringkas.
- Zero Cloud Cost: Seluruh fitur berjalan 100% lokal tanpa backend server berbayar atau API key berbayar.
- Hemat memori & CPU: Discord RPC dan Win32 tray harus ringan, tanpa library eksternal yang membebani startup.
- Kompatibel penuh dengan Windows WebView2 desktop environment.
- Transisi dan animasi halus 60fps dengan CSS hardware acceleration.
- Dokumentasi dan docstrings kode yang ada harus dijaga keutuhannya.

## Review Focus
1. **Keberagaman Artis FYP:** Feed rekomendasi FYP tidak boleh lagi didominasi oleh 1 artis saja; maksimal 2 lagu per artis dalam 16 lagu rekomendasi.
2. **Kontrol Media Hardware Tanpa Fokus:** Tombol Play/Pause/Next/Prev pada keyboard atau Bluetooth headset harus merespons pemutaran meskipun jendela Dengerin diminimalkan.
3. **Penyimpanan Offline Tanpa Internet:** Lagu yang disimpan offline harus dapat diputar langsung saat koneksi internet dimatikan (`$networkStore.isOnline === false`).
4. **Keamanan System Tray & Dialog Tutup:** Tombol "X" tidak boleh langsung mematikan aplikasi jika pengguna memilih tetap memutar musik di background; menu tray "Keluar Sepenuhnya" harus menghentikan seluruh proses Go secara bersih.
5. **Crossfade & Pre-fetch Mulus:** Pre-fetch 15 detik sebelum lagu usai tidak boleh menyebabkan lonjakan buffering atau audio glitch.
