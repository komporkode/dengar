# Dengerin v1.1.2: Equalizer, What's New Popup, Cinematic Hero, & Robust Playback Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menghadirkan fitur Audio Equalizer 5-Band dengan 8 preset, modal popup "What's New" / Changelog otomatis tiap pembaruan versi, perombakan Cinematic Full-Bleed Hero Banner pada halaman "Untuk Anda" (FYP), penguatan mesin pemutaran audio anti-gagal dengan auto-watchdog pemulihan instance, respons taktil instan saat lagu diklik, serta meningkatkan versi aplikasi ke `1.1.2`.

**Architecture:**
- **Backend Stream Engine (Go):** 
  - Memperbaiki validasi hostname `*.googlevideo.com` dan mencegah penulisan ulang URL googlevideo yang keliru pada resolver Invidious.
  - Menambahkan cooldown penalty pada instance yang bermasalah (429/timeout/500).
  - Menyediakan internal CORS streaming proxy (`/api/audio-proxy`) di `AssetServer.Handler` dengan dukungan header Range & status 206 Partial Content.
- **Frontend Playback & Tactile UX:**
  - Menambahkan buffer/stall watchdog 6 detik pada `playerStore.ts` untuk memulihkan pemutaran secara otomatis jika stream membeku.
  - Micro-haptic tactile feedback: visual scale `active:scale-[0.98]`, immediate audio wave/spinner pada baris lagu yang diklik, dan state pemutar yang reaktif.
- **Frontend Audio (Web Audio API):** `equalizerStore.ts` mengelola `AudioContext`, 5 node `BiquadFilterNode` (60Hz, 230Hz, 910Hz, 3.6kHz, 14kHz), switch bypass ON/OFF, 8 preset audio, dan sinkronisasi `localStorage`.
- **UI Components:**
  - `EqualizerDrawer.svelte` & `SettingsModal.svelte`: Kontrol visual equalizer di player bar dan tab pengaturan audio.
  - `WhatsNewModal.svelte`: Dialog modal informasi pembaruan versi baru berbasis offline dictionary (`changelogs.ts`) yang muncul sekali saat versi baru terdeteksi via `localStorage`.
  - `ForYouView.svelte`: Perombakan hero banner dari format kotak kaku menjadi Cinematic Full-Bleed Hero dengan ambient gradient blending ke warna dasar `#090A0E`, tipografi besar, dan horizontal carousel koleksi.
- **Versioning:** Pembaruan versi minor dari `1.1.1` ke `1.1.2` di seluruh konfigurasi (Go, Wails, Svelte, NSIS, CI workflow).

**Tech Stack:** Go 1.25, Wails v2, Svelte 5, TypeScript, Web Audio API, Tailwind CSS v4.

**Spec:** Sesi Grilling Round 1 & referensi gambar Flume: Skin (`media_1793328339139_e702e718.jpg`).

## Global Constraints
- Bahasa antarmuka: Bahasa Indonesia yang ramah, ringkas, dan modern.
- Tetap hemat memori, tanpa ketergantungan library eksternal baru (Zero bloat).
- Kompatibel dengan Windows WebView2 desktop environment.
- Transisi dan animasi harus 60fps dengan CSS hardware acceleration.
- Dokumentasi dan docstrings kode yang ada harus dijaga keutuhannya.

## Review Focus
1. **Pencegahan Gagal Putar:** Hostname googlevideo dan fallback instance pool harus mampu memutar lagu kompilasi panjang maupun lagu pendek tanpa hang.
2. **Tactile Feedback:** Klik pada track item harus langsung memberikan umpan balik visual instan (gelombang suara/spinner) tanpa delay.
3. **Audio Streaming & CORS:** Streaming audio harus tetap berjalan normal dan dapat di-scrubbing (seek) saat Equalizer aktif maupun tidak aktif.
4. **Fallback Web Audio:** Jika Web Audio API gagal diinisialisasi (misal browser audio policy), audio playback harus tetap menyala normal secara fallback tanpa throwing unhandled error.
5. **What's New Trigger:** Modal hanya boleh muncul tepat sekali untuk tiap versi; tidak boleh muncul berulang kali setiap kali aplikasi dibuka.
6. **Respon Tampilan Hero Banner:** Visual cinematic hero harus fleksibel di berbagai resolusi jendela (mulai dari 900px hingga layar lebar) tanpa gambar pecah atau teks terpotong.
7. **Versi Konsisten:** String `1.1.2` harus tercermin secara konsisten di jendela About, file biner, installer, dan status updater.
